# Проект "Музыкальный плеер"
Работу выполнил Круглов Никита
## ТЗ
Проект должен представлять из себя музыкальный плеер, способный сохранять и загружать 
плейлисты, используя csv, и редактировать аудио-файлы.
### Классы
#### MusicApp(QMainWindow)
Главное окно приложения. Около и ниже центра располагаются две кнопки "Плейлист" и "Плеер", открывающие 
Music_list(QWidget) и Music_Player(QWidget) соответственно. Вверху расположены кнопки "Поставить картинку" и "История прослушиваний",
открывающие Settings(QWidget) и History(QWidget) соответственно.
#### Music_list(QWidget)
В окне представленно шесть кнопок: три, управляющие аудио-файлами в плейлисте (Добавить файл, добавить файли из папки, удалить файл), две управлением плейлистами и "Редактировать аудио-файл",
открывающая Redactor(QWidget).

Плейлист может быть загружен с удалением уже имеющихся аудио-файлов, а может и без.

Двойной клик по элементу списка активирует воспроизведение соответсвующего файла.
#### Music_Player(QWidget)
В этом окне можно начать воспроизведение аудио-файлов из плейлиста в **Music_list(QWidget)**. 

Прогресс воспроизведения будет отображаться на двух label-ах и ползунке, с помощью которого можно перематывать аудио-файл.

Если плейлист пуст, то откроется **Music_list(QWidget)**.

В окне есть кнопка, открывающая **Music_list(QWidget)**

Если файл уже воспроизводится, то надпись "Старт" на кнопке поменяется на "Пауза"

Кнопка "Следующая песня" позволит воспроизвести следующий в плейлисте аудио-файл. Если файл последний, то воспроизведётся первый в списке аудио-файл.

Если RadioButton "автовоспроизведение" активирована, то по окончанию аудио-файла, начнёт проигрываться следующий.

Посередине окна находится *картинка*

#### Settings(QWidget)
В окне можно поменять картинку стоящую в **Music_Player(QWidget)**.

При выборе картинки из списка она будет выведена в окно в качестве предосмотра. Двойной клик выбирает картинку.

Можно добавить свою картинку.

Возможно удаление картинок из списка.

#### History(QWidget)
В окне отображается история воспроизводимых файлов. Можно посмотреть название, местоположение в компьютере и дату/время проигрывания аудио-файла.

Историю можно *очистить*.

#### Redactor(QWidget)
В окне можно вырезать кусок из выбранного файла, убавить/прибавить громкость и склеть с файлом другим.

Чтобы сохранить новый файл необходимо вписать путь сохранения и название.

Присутствует RadioButton, при активированности которого редактированный файл сразу добавляется в плейлист.

#### CustomDialog(QDialog)
Вызывается при загрузке плейлиста. Спрашивает, нужно ли оставить старые аудио-файлы.

### Ошибки
Все возможные ошибки, которые могут спровоцировать приложение заглючить, должны пресекаться и вызывать QMessageBox, обясняющий ошибку.
